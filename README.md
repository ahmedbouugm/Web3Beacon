# Web3Beacon

Web3Beacon enables event-driven data synchronization and decentralized, blockchain-based storage for real-time node-to-network updates.

Web3Beacon is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/Web3Beacon.git`
2. `cd Web3Beacon`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure Web3Beacon, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
